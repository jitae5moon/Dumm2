# Dumm2 Projects

**Dumm2** is a monorepo for collecting and managing multiple prototype projects.  
Each subproject is designed to experiment with or demonstrate specific features, architectures, or ideas.

- `board` – A reusable and extensible bulletin board system
  - `admin`: Admin backoffice (Spring Boot + Thymeleaf)
  - `api`: Backend APIs (Spring Boot + JPA)
  - `portal`: User-facing frontend (Vue.js)
